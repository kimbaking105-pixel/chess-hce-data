# chess-hce-data

Сбор данных для обучения компактной HCE: самоигра движков → тихие позиции → метка по результату партии.

Метки — только результат партии. Оценки Stockfish, Blunder и других движков не используются как метки.

## Состав
- `scripts/selfplay.py` — самоигра двух UCI-движков, контроль base+inc (по умолчанию 5 с + 0.1 с), случайные открытия, обмен цветов.
- `scripts/extract.py` — тихие позиции (без шаха, взятий, превращений), полуходы 10…(конец−10), не больше 30 позиций на партию, метка с точки зрения стороны, которая ходит.
- `.github/workflows/datagen.yml` — матрица из 10 задач × 4 процесса (по одному на ядро).
- `data/` — пилотные файлы (не в репозиторий, если объём велик).

## Запуск локально
```
python3 scripts/selfplay.py --a ./build12 --b ./build12 --pairs 10 --seed 1 --out data/games.jsonl --tag bb
python3 scripts/extract.py --in data/games.jsonl --out data/positions.jsonl --cap 30
```
